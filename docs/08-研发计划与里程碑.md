## 2. 逐期详情

### M0 骨架（`9c0e2b3`）

交付：`dev.v1` proto（Product/System）、ent schema、Atlas 迁移 0001、outbox + relay、
OIDC 拦截器与 fail-closed 授权矩阵、healthz/metrics、Next.js 只读控制台、数据包规范。

证据：
- `make check` 全绿；`make test-integration` 真连 PG（含 RLS 跨组织）；
- grpcurl 创建/重放/冲突；outbox 投递到 `DEVMASTER_EVENTS`；`PingWorkflow` COMPLETED。

### M1 工作项（`6369cd5`）

交付：五类型、按类型固定状态机与守卫、CAS、append-only 事件日志、评论/链接、
pg_trgm 中文搜索、数据包导入器、事件折叠对账。

证据：
- 状态机**每一条边**穷举测试；rank 性质测试；
- `m1-smoke` 重复导入 0 新建；`make reconcile` 5 条 0 不一致；
- gRPC 创建→指派→TODO→IN_PROGRESS，过期版本写入返回 `AlreadyExists`。

### M2 看板与冲刺（`b514545`）

交付：四列看板、冲刺生命周期、范围事件、蔓延率、每日燃尽快照、rank 重平衡。

证据：
- 12 路并发拖拽后 rank 无重复；相邻 rank 耗尽自动重排；
- committed 8 → 启动后加 2 点 → `creepRate=0.25`；
- 看板页渲染 Sprint 24 与三张卡片。

### M3 版本与发布（`6e69e2c`）

交付：版本生命周期、发布记录、四眼校验、approver HTTP 客户端、ReleaseWorkflow、
Gitea 打 tag、E9 自寻址事件 + consumer inbox 幂等、发布后范围冻结。

证据：
- approver 真实实例：提交 → 审批 → `v1.0.0` tag → `PUBLISHED` → E6 已投递；
- 冻结后 `AssignVersionItems` 与 `UpdateWorkItem` 均返回 `FailedPrecondition`。

欠账：artifact 证据只存 `notes_ref`/`evidence_ref` 引用，未接 artifact 客户端（M5 计划内，未做）。

### M4 代码与工时（`8b2c0a2`，PPM `cbfc149`）

交付：Gitea webhook（HMAC + delivery 幂等）、提交关联、PR 状态回填、每日对账、
工时记录/更正（append-only）、E7/E8 出站。

证据：
- 真实 push `HOSP-5 #done` → webhook 关联；关闭 webhook 推 `HOSP-6` → 对账补齐；
- 关联率 100%；工时 90 分钟 + 更正 -90 → PPM `+4,500,000 / -4,500,000`，净额 0。

跨仓修复：PPM 曾把 `author_id` 强制 UUID，devmaster 的 `local-dev` 被拒；
PPM 已放宽为“非空字符串”。

欠账：PR 状态按 head 分支回填（webhook 不带 commit 列表），跨分支 PR 需要额外拉取。

### M5 集成收口（`64aa527`，it-solution `7f5b08a`/`785a9b7`）

`CreateDeployment` 前置校验（fail_closed / fail_open_with_flag）。
